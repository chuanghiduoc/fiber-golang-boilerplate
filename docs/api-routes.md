# Canonical API route map

Target HTTP surface for every module. This is the design module agents implement
through `internal/platform/httpapi`; it is not a description of the current
(unconverted) Fiber tables. The machine-readable version is
[`openapi.yaml`](openapi.yaml), generated by `go run ./cmd/openapi`. That file
currently documents the platform-owned probes; a module's operations appear as
soon as its `RouteProvider` conversion lands, with no generator change.

## Conventions

- **One version.** Every module operation is under `/api/v1`. `/api/v2`,
  `Accept-Version`, `API-Version`, and deprecation headers are removed. The
  version is part of the path and nowhere else.
- **Collections are plural, lower-kebab-case.** `/members`, `/roles`,
  `/webhooks/endpoints`, `/me/api-keys`. No trailing slash, no `/admin`.
- **Caller-owned resources live under `/me`.** Profile, sessions, MFA factors
  and passkeys, API keys, data exports, erasure requests, notifications, and
  notification preferences.
- **Tenant administration lives at the collection.** `/members/{memberId}`,
  `/invitations`, `/roles`, `/files`, `/webhooks/...`, `/stats`.
- **Cross-tenant administration lives under `/platform`.** Tenants, a user's
  MFA reset, and feature flags. Platform permissions imply a phishing-resistant
  passkey MFA check (`hwk`/`swk`); a TOTP code is not sufficient.
- **Auth flows live under `/auth`.** Registration, login, refresh, logout,
  password reset, email verification, Google, MFA challenge verification, and
  passkey login ceremonies.
- **Public receivers** are limited to `/webhooks/inbound/{sourceId}` (source
  HMAC) and the auth flows marked Public below.
- **Custom methods use one syntax:** `POST /resource/{id}/verb`, for example
  `POST /files/{fileId}/restore`. The colon form
  (`/resource/{id}:verb`) is rejected because Fiber reserves `:` for path
  parameters. A custom method is used only when a state field does not fit.
  Retired spellings (`/revoke`, `/ban`, `/upload`, `/download`, `/read`,
  `/status`, `/role`) are not part of the target.
- **IDs are UUIDv7 strings.** Path parameters are camelCase
  (`{memberId}`, `{fileId}`); query parameters are camelCase.
- **PATCH is RFC 7396 merge patch** with `Content-Type:
  application/merge-patch+json`: an absent member is unchanged, an explicit
  `null` clears the field, any other value replaces it. `pkg/patch.Field[T]`
  encodes the DTO side; `patch.Merge` is the free-form escape hatch.
- **Config resources carry `ETag` and honour `If-Match`.** Tenant roles,
  feature flags, webhook endpoints/sources, and tenants return an `ETag` on
  read/update and answer a stale `If-Match` with `412
  resource.precondition_failed`. A missing `If-Match` is unconditional.
  `httpapi.SetETag`/`httpapi.CheckIfMatch` are the helpers.
- **Idempotency** is opt-in with `Idempotency-Key` on mutations where a retry is
  meaningful. It is never added to token/secret-returning operations.
- **No store.** Token-, secret-, and export-returning operations set
  `Cache-Control: no-store` through the policy.
- **Browser token transport.** With `AUTH_REFRESH_COOKIE=true`, token responses
  set `__Host-refresh` and omit `refreshToken` from JSON; refresh/logout read
  it and enforce the CSRF rule (`403 auth.csrf_failed`). The JSON body stays
  optional on those two operations.
- **Feature gates are policy.** `Policy.Feature` runs after authorization and
  before idempotency/audit; a disabled flag is `404 feature.disabled` with no
  lock or intent row.
- **If-Match is a SQL compare-and-swap.** The UPDATE carries the version
  predicate; 0 rows is `412 resource.precondition_failed` when the row exists
  and `404` when it does not.
- **Audit.** Every mutation is Tier 1 (the owning service records the named
  action in its transaction) or Guarded (the HTTP layer writes a required
  intent row after idempotency). Best-effort Guards are only for the caller's
  own notification state and must be allowlisted in `test/arch`.
- **Responses.** `201` carries `Location`; `202` carries `Location` of the
  status resource for accepted asynchronous work; no-body success is `204`; no
  `{"message": ...}` bodies. Lists use
  `{object:"list",url,data,hasMore,nextCursor}` (`pagination.List[T]`).

Policy shorthand in the tables: `Public` / `Permission` / `AnyOf` / `JWT-only`
/ `MFA` / rate tier (`strict`, `normal`, `relaxed`, `none`) / `Idempotent` /
`Tier1(action)` or `Guard(action)` / `ETag` / `No-store`.
